# Salesforce CRM Dev Starter
## Description
Beginner Salesforce CRM Developer project demonstrating Salesforce DX, Apex, SOQL, Flows, and integration concepts with MuleSoft.

## Features
- Salesforce DX project structure
- Apex classes
- SOQL queries
- Apex test coverage
- CRM automation concepts
- Integration-ready architecture

## Technologies
- Salesforce DX
- Apex
- SOQL
- Flow
- MuleSoft Integration Concepts

## Sample Business Flow
External system → MuleSoft → Salesforce → Flow Trigger → CRM automation
